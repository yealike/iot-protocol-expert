# 多设备接入与模拟：审查记录

2026-11-12：多设备行为已归并到 Java 模拟器模块；通用 Modbus/MQTT 采集归协议模块。模拟器提供只绑定本机的 Modbus 服务、可选 MQTT 发布和仅供本地模拟的 MQTT Broker，模拟控制入口使用独立令牌并通过固定 SIM 编号与动作白名单限制；响应超时为 UNKNOWN。模拟命令只适用于本机模拟设备。

Java 自动测试覆盖真实 TCP 字节收发、本机模拟 Broker 端到端、设备状态及命令权限；未验证外部生产 Broker、PostgreSQL 全链路、真实厂商硬件及浏览器 3D 渲染。启动和配置见 [多设备模拟与协议采集](multi-device-java.md)。

生产前仍需网关级鉴权及细粒度授权、MQTT 持久投递与幂等、时序乱序处理、告警状态恢复、设备真实控制及现场联锁。`/internal/properties` 使用高权限内部令牌，不应暴露给不受信任的设备；现有浏览器 CSRF 防护、协议通道内部命令身份校验问题也仍需处理。摄像机没有真实 ONVIF/视频实现。厂商采集示例需要按型号和固件核对点位及无效值。
