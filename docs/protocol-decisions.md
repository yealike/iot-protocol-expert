# 协议歧义与实现规则

依据本地《云快充平台协议V1.6新》2020-10-29版本。协议字段以各节正式字段表为准，不照抄样例中的错号和占位CRC。

1. **CRC多项式**：正文§3.1写0x180D，附录提供Modbus算法/查表。采用附录反射多项式0xA001、初值0xFFFF、低字节先，使用已有文档0x06样例CRC `8E2F` 验证。
2. **长度与卡数量冲突**：§3.1规定数据域最多200字节，而卡同步15张、清除24张、查询26张的数量上限会超过200，清除/查询应答还可能更长。帧层严格限制200；平台以同步11张、清除18张、查询20张分批，兼容3DES补齐，合并应答返回调用方。
3. **BMS倍率与偏移**：按字段表实现；电流为0.1A/位、-400A偏移，温度-50℃偏移，生产年份1985偏移，单体编号/探针编号/充电机编号为1偏移。`0x23` 单体电压低12位、高4位组号分别暴露。充电电流在BMS报文中以负电流表达。
4. **0x17当前电池电压**：表中只写“整车动力蓄电池总电压”，未明确0.1倍率。保留该字段原始整数，字段元数据明确标注，不自行套用其他电压字段倍率。
5. **交易确认含义**：§8.7描述30秒重试最多3次；§8.8又描述5分钟后最后重发一次，且声明收到报文不等于资金结算。采用§8.7三次重试；待传账单只在成功确认时移出，重试用尽保留本地，重新登录再次尝试。平台的SETTLED是本工程参考订单状态，不表示真实支付结算。
6. **并充模式**：§12.2要求全部枪成功后才一起启动；后续实时和账单各枪各自流水。因此实施分枪计费，使用同一并充序号关联，不把两枪伪造成一笔协议交易。控制台APP并充覆盖该桩配置的全部枪。
7. **费率切换**：规范建议空闲下发；模拟器可以接收新模型，但活动订单保存启动时费率快照，新的价格仅用于下一笔订单，避免一笔0x3B同一费率类型出现多个无法表达的单价。
8. **计损**：按“实际电量×(1+计损比例/100)”计算计损电量和费用；平台规范默认不启用、比例0。
9. **对时**：对时前积算已有充电，对时跳变不产生能量；活动订单的起点和积分游标同量平移，既有分时电量不重算。用于模拟环境；对时应尽量在空闲执行。
10. **参数查看**：规范只有工作参数设置及应答，没有远程参数读取帧。通过模拟器REST显示本地真实配置及下发后的生效值，不创造未定义的云快充帧类型。
11. **物理卡字段**：二进制、8字节、不足左补0。卡查询/清除基于真实持久白名单；合法卡重复清除视为幂等成功。
12. **模拟与真实硬件**：FTP升级模拟结果不执行外部固件；BMS消息为字段级仿真，不实现CAN链路；参考平台鉴权不对接真实账户资金系统。启动方式0x02帐号在规范中注明暂不支持，界面提供APP、卡、VIN及离线卡。
13. **断电恢复精度**：活动订单每秒检查点。异常退出后恢复的电量截至最后保存点，按0x83生成账单；不根据进程离线时长猜测硬件充电量。
