# 充电枪线软体物理

## 现成方案调研与选择

| 方案 | 官方依据 | 本项目选择 |
| --- | --- | --- |
| Three.js + Ammo.js/Bullet 软体绳索 | [r180 官方 rope 示例](https://github.com/mrdoob/three.js/blob/r180/examples/physics_ammo_rope.html)，[Ammo.js](https://github.com/kripken/ammo.js) | **采用**。本项目 Three.js r180 已附带兼容的 Ammo WASM，直接复用软体引擎。 |
| NVIDIA PhysX PBD 粒子 | [PhysX 5.4.1 文档](https://nvidia-omniverse.github.io/PhysX/physx/5.4.1/docs/ParticleSystem.html) | 有成熟粒子约束方案，但该接口需要 CUDA GPU 与原生运行环境，不直接接入浏览器。 |
| Rapier 软体 rope | [JavaScript 0.21 soft-body 文档](https://rapier.rs/docs/user_guides/javascript/soft_bodies/) | 也是可选实现；当前优先使用与已有 Three.js 版本配套的 Ammo。 |

`public/simulator/vendor/ammo/` 中的 JS/WASM 从已安装的 Three.js r180 包复制，保持原文件内容，保留 Ammo zlib 许可。新增约 1.05 MB 本地运行时，资源本地加载。使用 `btSoftRigidDynamicsWorld`、`btSoftBodyHelpers.CreateRope`、结构/弯曲约束与软体—刚体碰撞，由物理求解驱动动态形态。

## 充电枪线参数

- 每根线缆长度 5 m，依据星星双子座 V3.2 规格书的标配枪线；64 段 / 65 个节点。
- 重力 9.81 m/s²；总质量 8 kg；线径沿用模型的 52 mm；动摩擦 0.85、速度阻尼 0.025、弯曲约束刚度 0.18。这些是展示调校参数，没有声称通过真实线缆的材料试验标定。
- 柜体出线口和枪柄末端固定；额外约束两端相邻节点，保持出线套和枪柄的自然出线方向。
- 地面、柜体、车辆下方/车体及轮挡作为刚体碰撞物。曲面蒙皮对地面和柜体角部增加线径保护，避免插值出现小范围穿模。
- Bullet 的 1D rope 没有三角面，默认软体的顶点/面碰撞不能直接处理枪线互相穿过；在 Ammo 物理步后增加有限线径的线段胶囊接触约束，处理自身和两根线之间的接触。近地面交叉时，上方线缆会抬起叠放；同时修正物理节点的当前位置和上一位置，避免位置修正凭空注入速度。引擎 JS/WASM 本身未修改。
- 初始余线按正确长度平铺在柜体两侧，加载前预演 3 秒，让重力和摩擦达到稳定；正常显示为两段下垂加贴地余线。
- 插枪/收枪只改变枪端固定点，**不重置整根线缆**：近端被逐渐拉起，地面部分拖动；停止移枪后仍保留速度，通过阻尼与地面摩擦逐渐停下。收枪后依靠重力回落，不自动缩短线长。
- 切换设备/枪时才重置到新设备的稳定状态，避免把业务上的切换误当作高速甩动。
- 固定 120 Hz 物理步长，单帧最多补 12 步；动态管状网格复用顶点缓冲，不在每帧销毁重建几何。退出页面时销毁物理世界、软体、刚体和显示网格。

## 验证

执行：

```powershell
node --test tools/cable-physics.test.mjs tools/twin-geometry.test.mjs
```

测试直接运行项目中的 Ammo WASM，验证实际软体节点与渲染蒙皮：

1. 稳定后，65 个节点中 37 个接触地面；长度约 4.997 m，端点仍与出线口/枪柄一致。
2. 完整插拔周期内，含线缆自身接触修正的最大长度约 5.044 m（约 0.9% 数值偏差）；线缆运动连续，固定枪端后仍有惯性；回收后 36 个节点重新贴地。
3. 检查物理节点和蒙皮不穿地面/柜体；独立使用 Three.js 点/线段距离检查回落线缆的自接触和互相接触间隙；检查顶点缓冲复用、管壁朝向正确，以及开盖完成后才移枪、收枪归位后才合盖。

上述数值对应验收场景中的固定运动轨迹，是实时展示验证，不是电缆力学或弯曲半径认证。
